#1 · 356 赞v1

视频生成能否跟上连续指令？

StreamEval: Evaluating Interactive Streaming Video Generation Models

arXiv 2610.28402 · 首发 2026-10-20（UTC）
StreamEval Team
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
单段视频质量无法说明流式模型能否在用户连续改要求时及时执行，并保留此前仍然有效的状态。
方法
构造头像对话、表演、世界生成和两类编辑任务；脚本规定输入到达时刻、修改目标和保留要求，从执行、状态一致性、画质及音画协调评估全过程。
结果
作者报告：覆盖 300 个 15–300 秒案例、37 个模型；高画质不保证可靠执行。参考编辑中所报告模型的最高 Edit Success 为 15.00/100。

值得看适合设计实时多模态产品的过程评测。

阅读判断 任务分数按各自指标定义，不能混作统一成功率；基准不等于部署延迟测试。

#2 · 129 赞v1

让视觉 Agent 主动探索并画出三维地图

SpatialScout: Can VLM Agents Actively Explore and Map 3D Scenes?

arXiv 2610.26659 · 首发 2026-10-19（UTC）
Zhaoxi Zhang 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
空间问答可借猜测和语言先验答对，却无法检验 Agent 是否能主动收集证据、构建完整精确的三维坐标图。
方法
在 80 个室内场景提供物体清单、RGB 观测和相机标定/位姿；Agent 自主选视角，融合几何证据估计物体中心并修订地图，评分同时考虑定位与漏检。
结果
作者报告：3,140 个目标中，最强受测模型平均 overlap 为 41.71%；47.23% 目标超过 IoU 0.5，3.25% 超过 0.9。

值得看把主动感知、跨视角关联和地图维护放进同一个闭环。

阅读判断 提供相机几何信息，不能直接代表无标定真实机器人导航能力。

#3 · 125 赞v1

用人类示范训练通用双手控制

DONIC: Generalist Dexterous Bimanual Tracking Control from Human Demonstrations

arXiv 2610.29997 · 首发 2026-10-21（UTC）
Mingze Sun、Ziang Cao、Yuan Fei 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
现有灵巧跟踪偏重单手；双手接触数据稀缺，角色不对称和示范难度差异使统一策略难训练。
方法
将 BiHOI 多视角人手物体轨迹重定向到机器人；用以物体为中心的逐手接触奖励、片段中心化优势，结合 PPO 与行为克隆，并将验证成功的执行回收为示范。

LoopRecv1

关键历史物品值得多算几层

Think Harder Where It Matters: Item-Level Adaptive Recursion for Sequential Recommendation

arXiv 2610.30128 · 首发 2026-10-21（UTC）
Zhanshuo Cao、Jiakai Tang 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
序列推荐通常给每个历史物品相同深度，但大部分行为很早稳定，少数关键行为需要更多计算。
方法
反复使用同一个共享参数块；每轮根据当前状态逐物品决定退出或继续，最后从各自退出深度读出表示。训练加入深度使用平衡与门控稳定项，无需深度标签。
结果
作者报告：三个数据集、四类骨干均优于匹配的固定深度模型。文中 8.8% HR@20 相对增益来自知道目标的诊断 oracle，不能当作 LoopRec 实测增益。

值得看为推荐中的推理计算分配提供可复用设计。

阅读判断 动态路由节约的局部计算不能直接等同端到端延迟下降。

CAPEv1

生成式推荐的长尾要补两次

Generative Recommenders Forget the Long Tail: Restoring Memorization in Retrieval and Ranking

arXiv 2610.29298 · 首发 2026-10-21（UTC）
Xu Huang、Jiancan Wu 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
长尾物品既在 beam 前缀剪枝时被漏掉，即使补进候选，也可能被同一生成似然排到后面；单纯加宽 beam 不够。
方法

值得看可作为现有生成式推荐的免训练补丁。

阅读判断 依赖历史共现统计；极冷物品缺少协同证据，首位锚定也限制最顶位改动。

已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD

CORDv1

别让强化学习与蒸馏互相抵消

CORD: Conflict-Aware Optimization for Joint RL and Distillation in Agents

arXiv 2610.29965 · 首发 2026-10-21（UTC）
Wenhao Yu、Zhengcheng Wang 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
RL 的任务奖励和蒸馏的稠密指导可能梯度相反；调整混合系数只能缩放，不能选择性移除冲突分量。
方法
在优化器 mini-batch 粒度累积梯度，明确选择保护目标与投影触发条件；保持保护梯度，最小修改另一梯度的反向分量，再合并更新。
结果
作者报告：三种联合训练配方在 ALFWorld 提升 1.5–15.9 个百分点；WebShop 中两个配方改善，SDAR 从 60.7% 到 64.6%。

值得看为联合训练增加一个清晰的梯度层干预点。

阅读判断 保护方向和门控要一起选择；一阶几何保证发生在优化器变换之前，不保证所有环境都提升。

Behavior Mapsv1

不跑新轨迹也能比较 Agent 行为

Agent Behavior Maps: Locating Agents by What They Would Do, Without Running Them

arXiv 2610.30014 · 首发 2026-10-21（UTC）
Shota Fujikawa、Takuya Tamura 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
相近成功率可能掩盖完全不同的行动路径；逐一运行模型与 harness 的所有组合成本很高。
方法
每个 Agent 用自己的 harness 重建共享轨迹上下文，对记录动作做 teacher forcing；将动作或整条轨迹的 log-likelihood 中心化为坐标，以距离估计策略行为差异。
结果
作者报告：100 个 LLM、四个环境的实验支持性能预测和行为近邻发现；八模型交叉评分中，坐标距离与轨迹 KL 排序相关。

值得看适合先筛选模型或 harness 组合，再投入昂贵的在线评测。

阅读判断 需要动作似然访问；理论依赖策略局部性、参考分布匹配，跨环境预测并非同等可靠。

EPICv1

用生成前缀约束离策略训练

EPIC: Rethinking Trust Regions for Autoregressive LLM Policies via Exact-KL Prefix Importance-Ratio Clipping

arXiv 2610.29999 · 首发 2026-10-21（UTC）
Chengxi Li、Hanlin Wu 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
逐 token PPO 限幅只看当前条件概率，忽略前缀本身随策略改变；异步生成的旧样本使长回复训练更容易漂移。
方法
将生成写成有限时域 MDP，以前缀累积似然比做重要性校正；用 r−1−log r 对应的精确 reverse-KL 坐标构造前缀信赖域，得到 PPO 式限幅目标。
结果
作者报告：稀疏 MoE 的离策略数学推理训练中优于所比较的标准与序列限幅基线，并与路由重放方案有竞争力。

值得看把限幅粒度与自回归生成的分布偏移联系起来。

阅读判断 实验集中于特定 MoE 和数学任务；过程 CPU 内存对比不能解读为 GPU 显存或训练延迟同幅改善。

SCDMv1

共享元学习扩展时序因果发现

SCDM: Scalable Causal Discovery in Nonlinear Temporal Systems with Meta-Learning

arXiv 2610.29992 · 首发 2026-10-21（UTC）
Jingbo Wang、Kegeng Tang、Zihao Wang、Shaogang Ren
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
变量数增长时，有向关系候选按平方增加；逐目标拟合、重复条件检验在非线性高维系统中代价高。
方法
每个目标变量定义一个预测任务，共享时序预测器及因果强度矩阵；每轮只抽样部分目标，做 support 适配和 query 更新，训练后用扰动式读出生成连续有向分数。

值得看适合关心多变量系统关系与可扩展性的方法研究。

阅读判断 恢复理论要求完全观测、延迟系统及风险间隔；有潜在混杂时不应直接解释成干预因果。

TCEEv1

让每笔交易检索自己的时序上下文

Leveraging Time-Series Foundation Models for Financial Crime Detection

arXiv 2610.29667 · 首发 2026-10-21（UTC）
Danae Natalie Savvidi、H. Çağrı Bilgi 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
图方法擅长账户关系，却常弱化交易节奏；把账户历史池化成单一向量，又无法区分同账户的不同交易。
方法

FloTS benchmarkv1

大气视宁度预测也需要概率分布

Probabilistic Machine Learning for Short-Term Atmospheric Seeing Forecasting

arXiv 2610.29654 · 首发 2026-10-21（UTC）
Mary Joe Medlej、Rahul Srinivasan 等
已读 HTML Introduction 与方法相关章节

INTRODUCTION / METHOD
问题
短时大气湍流影响观测规划，仅输出点预测无法表达不确定性；GP 的高斯假设限制预测分布形状。
方法
在 Maunakea 测量上比较 RNN、LSTM、GP 与 FloTS；FloTS 用历史 LSTM 编码为条件，以 masked autoregressive flow 建模未来分布，同时用确定性和概率指标评估。

值得看为概率预测方法选择提供一个具体应用中的对照。

阅读判断 是应用基准而非新流模型；站点和采样条件有限，不宜直接推广至其他气候与设备。
