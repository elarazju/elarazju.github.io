INTRODUCTION / METHOD
问题

不足

Shota Fujikawa, Takuya Tamura, Kosuke Akimoto, Daichi Haraguchi, Masafumi Oyamada

INTRODUCTION / METHOD
问题
相近成功率可能掩盖完全不同的行动路径；逐一运行模型与 harness 的所有组合成本很高。
不足

EPICv1

用生成前缀约束离策略训练

EPIC: Rethinking Trust Regions for Autoregressive LLM Policies via Exact-KL Prefix Importance-Ratio Clipping

作者：Chengxi Li, Hanlin Wu, Zhicheng Cai 等 7 位作者

Chengxi Li, Hanlin Wu, Zhicheng Cai, Huan-ang Gao, Wei-Ying Ma, Jingjing Liu, Hao Zhou

arXiv 2610.29999 · v1 · 首发 2026-10-21（UTC）

INTRODUCTION / METHOD
问题
逐 token PPO 限幅只看当前条件概率，忽略前缀本身随策略改变；异步生成的旧样本使长回复训练更容易漂移。
不足
逐 token 比率没有完整校正到达该前缀的概率；异步采样与策略滞后会放大离策略分布偏移。
方法
将生成写成有限时域 MDP，以前缀累积似然比做重要性校正；用 r−1−log r 对应的精确 reverse-KL 坐标构造前缀信赖域，得到 PPO 式限幅目标。
机制
累计到当前动作的前缀重要性比率；以 r−1−log r 的 reverse-KL 坐标界定限幅区间，再形成 PPO 式训练目标。

推荐理由 · 编辑判断把限幅粒度与自回归生成的分布偏移联系起来。

阅读边界 · 编辑判断 实验集中于特定 MoE 和数学任务；过程 CPU 内存对比不能解读为 GPU 显存或训练延迟同幅改善。

Danae Natalie Savvidi, H. Çağrı Bilgi, Kubilay Atasu, Arie van Deursen

arXiv 2610.29667 · v1 · 首发 2026-10-21（UTC）

INTRODUCTION / METHOD
问题
不规则交易历史既有时间模式又有账户关系，如何把时序基础模型用于犯罪检测？
不足
把账户压为固定节点向量，会给每笔交易同一上下文，难区分该交易需要的历史证据。
方法
冻结 Chronos-2 编码各账户事件序列；TCEE 用每笔交易作为查询，读取双方账户的时序特征。
机制
时间差与对手索引显式表示间隔和关系；逐边交叉注意力结合账户对池化、邻域窗口，可接 MLP 或 GNN。

推荐理由 · 编辑判断适合研究基础模型表示与图任务的接口，关键是让时间信息在边级而非只在节点级进入。

阅读边界 · 编辑判断 论文包含同分割完整历史和目标前后窗口，主要适用于离线分析；实时检测必须限制未来信息。

大气视宁度预测也需要概率分布

Probabilistic Machine Learning for Short-Term Atmospheric Seeing Forecasting

作者：Mary-Joe Medlej, Rahul Srinivasan, Simon Prunet 等 5 位作者

Mary-Joe Medlej, Rahul Srinivasan, Simon Prunet, Aziz Ziad, Christophe Giordano

arXiv 2610.29654 · v1 · 首发 2026-10-21（UTC）

INTRODUCTION / METHOD
问题
短时大气湍流影响观测规划，仅输出点预测无法表达不确定性；GP 的高斯假设限制预测分布形状。
不足
点预测不能表达随机湍流的不确定性；GP 的高斯分布与矩阵运算成本限制其表示与扩展。
方法
在 Maunakea 测量上比较 RNN、LSTM、GP 与 FloTS；FloTS 用历史 LSTM 编码为条件，以 masked autoregressive flow 建模未来分布，同时用确定性和概率指标评估。
机制
LSTM 把历史视宁度编码为条件，MAF 通过可逆变换学习未来分布，以似然训练并与 RNN、LSTM、GP 对照。

推荐理由 · 编辑判断为概率预测方法选择提供一个具体应用中的对照。

阅读边界 · 编辑判断 是应用基准而非新流模型；站点和采样条件有限，不宜直接推广至其他气候与设备。
