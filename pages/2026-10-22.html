#1 · 222 赞v1

让 GUI Agent 每一步只看关键信息

Focused Omni-Modal GUI Agents

arXiv 2610.26203 · 首发 2026-10-19（UTC）

问题
截图、音频与历史同时涌入，过时信息会累积成轨迹偏移。
方法
轻量适配器按当前决策选择相关模态，将压缩后的证据注入冻结模型的嵌入，无需微调骨干。
结果
作者在 4 个骨干上报告，Exact Match 相对冻结骨干平均达到 3.0 倍。

值得看适合研究长流程 GUI 的注意力分配。

多域 · 对话推荐v1

5.3M 参数，让多域对话推荐更轻

LightCRS: Lightweight Multi-Domain Conversational Recommendation System

arXiv 2610.26948 · 首发 2026-10-18（UTC）

问题
每个商品域各部署一个视觉语言模型，成本会随域数增长；混合训练又可能损失精度。
方法
冻结编码器离线算商品表示，在线用 5.3M 参数共享模块做查询交叉注意力，再联合比较候选。
结果
在作者构建的 25 域基准上，HR@1 较最强基线相对提升 35.4%，单次查询延迟降低 266 倍。

值得看适合多品类推荐的低延迟排序研究。

阅读判断 收益来自特定基准与基线，迁移时还需计入候选召回和离线编码成本。

多模态 · 多样性v1

从语义与图结构一起改善推荐多样性

Multimodal Decoupling for Diversified Recommendation through Semantic and Structural Shaping

arXiv 2610.26024 · 首发 2026-10-19（UTC）

问题
只优化准确率容易让推荐过度集中，多模态语义也常被 ID 表示压制。
方法
用多模态大模型解耦特征、按类别筛选语义，交替传播双图，再以熵正则平衡类别曝光。
结果
作者报告在真实数据集上获得更好的准确率与多样性权衡；摘要未给统一提升数值。

值得看值得拆开看语义特征、表示坍缩和训练偏置各自的贡献。

阅读判断 类别曝光更均衡，并不自动代表用户满意度更高。

新闻推荐 · 稀疏检索v1

把阅读历史聚合成可检索的稀疏偏好

LSNR: Learned Sparse News Recommendations with Attentive User Modeling

arXiv 2610.23510 · 首发 2026-10-16（UTC）

问题
把多篇新闻拼成一个查询，会混合不同兴趣，还会触发上下文截断。
方法
独立编码每篇文章，学习注意力权重聚合稀疏表示，并加入用户级稠密投影扩展。
结果
作者在 MIND、EBNeRD 上报告优于 STAR；服务索引较未压缩稠密基线小一个数量级。

值得看适合关注检索成本与短历史推荐的人。

阅读判断 索引大小结论的参照是未压缩稠密基线，不能直接推广到量化索引。

04 / LLM / AGENT

大模型与智能体 · 3 篇

本期聚焦 Agent 系统设计：接口能否自我改进，研究能否跨会话延续，重复决策能否复用。

接口进化v1

让 Agent 从任务经验中改进自己的接口

Evolving Agent Interfaces

arXiv 2610.28601 · 首发 2026-10-20（UTC）

问题
人为设计的工具与使用说明，难以跟上应用、工作流和模型变化。
方法
元 Agent 读取无成功标签的训练轨迹，修改接口仓库；种群进化用独立验证任务筛选改动。
结果
作者报告 Qwen3.8-27B 在 OSWorld V2 达 21.3% binary score，是固定接口的 3.8 倍。

值得看可把接口质量视作小模型能力提升的一个变量。

阅读判断 结果依赖进化与验证任务分布，真实部署还要检查泛化和接口权限。

持续科研 · 记忆v1

把跨会话研究组织成可积累的实验过程

Epi: Towards a Persistent, Self-Improving Agent for Autonomous Research

arXiv 2610.24944 · 首发 2026-10-18（UTC）

问题
长研究任务会跨越模型会话，容易丢失历史、重复失败路线。
方法
组合持久研究记录、分层记忆、分支探索和独立评审，由固定验证器评价实验输出。
结果
在 30 个 FrontierOR 任务上，作者报告 Épi-turbo 总分比 Codex 高 5.4%，模型成本为其 64%，底层模型与推理强度相同。

值得看值得看记忆如何服务于可检验的实验。

阅读判断 验证器覆盖的数学与优化任务，不能代表所有开放式科研。

决策复用 · MDPv1

把反复出现的决策先求解，再复用

Bellman Language Models: Solving the Recurring Decisions of LLM Agents

arXiv 2610.24871 · 首发 2026-10-17（UTC）

问题
有界工作流里相同状态反复出现，LLM 却每次都重新推理。
方法
从日志构建离散状态，估计转移概率和动作成本，求解 MDP；未知状态交回 LLM 处理。
结果
作者在 τ²-bench telecom 上报告 Qwen3.8-27B 从 29% 提升到 96%，模型调用减少 93%。

值得看适合流程稳定、决策空间可枚举的业务 Agent。

阅读判断 状态抽象错误或流程变化会削弱策略可靠性，未知状态回退机制很关键。

结构先验 · 长期预测v1

让相同时间滞后的连接共享参数

LagNet: Lag-Structured Operators for Long-Term Time Series Forecasting

arXiv 2610.23735 · 首发 2026-10-16（UTC）

问题
模型设计常关注输入编码，却较少约束“历史映射到未来”的算子结构。
方法
LagLayer 以 Toeplitz 结构绑定相同滞后的连接，再用历史位置和预测步缩放放松严格共享。
结果
作者报告其与强基线具有竞争力，少数据实验支持这种结构的样本效率；未宣称全面最优。

值得看值得作为时序线性层的替代模块研究。

阅读判断 共享滞后是归纳偏置，面对强非平稳序列需要额外验证。

8 天前首发 · 放宽至 14 天v2

不改预测模型，让 Agent 迭代部署管线

TimeRSI: Towards Self-Improved Agentic Deployment for Time-Series Foundation Models

arXiv 2610.19725 · 首发 2026-10-14 · 更新 2026-10-15（UTC）

问题
零样本时序模型虽强，输入输出设计与反复出现的误差仍需要人工处理。
方法
冻结预测模型，让编码 Agent 修改管线、在历史窗口回测，再依据相似已完成预测选择管线。
结果
作者在 TIME、fev-bench 共 198 个任务上，报告 6 项点预测与概率预测指标优于各提交方案。

值得看适合研究基础模型的最后一公里部署。

阅读判断 必须严守时间切分，并把迭代搜索的额外算力纳入总成本。

8 天前首发 · 放宽至 14 天v1

以循环深度学习上下文中的动力学

Test-Time Forecasting: Recurrent Depth Enables In-Context Dynamics Prediction

arXiv 2610.19552 · 首发 2026-10-14（UTC）

问题
动力系统基础模型是否学会了可迁移的预测策略，而不只是记住训练系统？
方法
连接线性注意力与动态模态分解，把梯度下降迭代用作循环深度，构建单步预测器。
结果
作者报告在 ODE、PDE 上训练的轻量模型，在自回归展开中能泛化到分布外动力学；摘要未给统一误差降幅。

值得看适合关注测试时计算与动力系统预测的人。

阅读判断 动力学基准的泛化，仍需在业务时间序列上另行验证。
